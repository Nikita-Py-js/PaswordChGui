# PaswordChGui

Графический клиент службы [PaswordChService](https://github.com/Nikita-Py-js/PaswordChService). Позволяет менять пароли пользователей без командной строки.

[![WPF](https://img.shields.io/badge/UI-WPF-5C2D91.svg)](#архитектура)

## Что это

Небольшое WPF-приложение, которое работает **через тот же именованный канал**, что и консольный `PaswordChService.exe`. Служба остаётся работать в фоне под `LocalSystem`, GUI лишь отправляет ей запросы.

Основные возможности:

- **Сменить свой пароль** — без прав администратора.
- **Сменить пароль другого пользователя** — для менеджеров.
- **Массовая смена паролей** для всех из `emails.csv` — с подтверждением и списком результатов.
- **Просмотр статуса** — связь со службой, интервал, дата следующей смены.
- **Роль пользователя** определяется автоматически из `my.ini`.

## Установка

### Вариант 1. Вместе со службой

1. Скопируйте `PaswordChGui.exe` рядом с `PaswordChService.exe` в `C:\Program Files\PaswordCh\`.
2. Создайте ярлык на рабочем столе.
3. Запускайте GUI под своей обычной учётной записью.

### Вариант 2. Отдельно

1. Скопируйте `PaswordChGui.exe` в любую удобную папку (например, `%LOCALAPPDATA%\PaswordChGui\`).
2. Убедитесь, что служба установлена в `C:\Program Files\PaswordCh\` — GUI автоматически найдёт `my.ini` оттуда.
3. Запускайте двойным кликом.

> **Права администратора не нужны.** Все операции идут через named pipe — служба делает всё под своей учётной записью.

## Как пользоваться

### Обычный пользователь

1. Открыть GUI.
2. Вкладка **Сменить пароль**.
3. Поле логина — **оставить пустым**.
4. Нажать **Сменить пароль**.
5. Получить новый пароль в блоке результата.

> **Примечание.** Если в `my.ini` включена отправка по email (`SendEmailsToUsers=true`), вы также получите письмо с новым паролем или одноразовой ссылкой.

### Менеджер

Менеджер — это пользователь, указанный в `Managers` в `my.ini`. Он может:

1. **Сменить свой пароль** — так же, как обычный.
2. **Сменить пароль конкретному пользователю:**
   - Вкладка **Сменить пароль**.
   - Ввести логин пользователя в поле.
   - Нажать **Сменить пароль**.
3. **Сменить пароли всем:**
   - Вкладка **Статус**.
   - Нажать **Сменить пароли всем**.
   - В диалоге подтверждения нажать **Да**.
   - Дождаться завершения и просмотреть список результатов.

### Что происходит при массовой смене

При нажатии **«Сменить пароли всем»**:

1. Появляется диалог подтверждения с полным списком последствий.
2. При **Нет** — операция отменяется, в статусе «Массовая смена отменена».
3. При **Да** — GUI отправляет службе команду `RUN|`.
4. Служба выполняет полный цикл: меняет пароли всем незащищённым, отправляет письма, сохраняет ZIP.
5. Результаты по каждому пользователю появляются в таблице под опасной зоной.
6. Счётчик «Следующая смена» обновляется автоматически.

**Отменить операцию после запуска нельзя.** Диалог честно об этом предупреждает.

## Роли

Роль определяется автоматически из `my.ini` на основе вашего логина.

| Роль | Что может |
|---|---|
| **Обычный** | Сменить только свой пароль |
| **Менеджер** | Сменить свой и чужие пароли, массовая смена |
| **Менеджер (защищённый)** | Меняет чужие, но свой пароль защищён |
| **Защищённый** | Не может сменить даже свой |

Роль отображается в шапке окна справа вверху.

## Индикатор статуса

В подвале окна — цветной индикатор и текст:

| Цвет | Значение |
|---|---|
| 🟢 Зелёный | Служба отвечает, всё в порядке / операция выполнена |
| 🟡 Жёлтый | Идёт операция / связь проверяется |
| 🔴 Красный | Ошибка / служба недоступна |

**Если служба не запущена** — при нажатии любой кнопки GUI покажет красный индикатор и подсказку:

```
Служба PaswordChService не запущена. Запустите её командой: sc start PaswordChService
```

## Архитектура

```
PaswordChGui.exe
├── MainWindow.xaml              — окно с вкладками
├── App.xaml / App.xaml.cs       — точка входа, глобальный обработчик исключений
├── Styles\Colors.xaml           — палитра EFSOL, стили кнопок, вкладок
├── Infrastructure\
│   ├── ObservableObject.cs      — база MVVM (INotifyPropertyChanged)
│   ├── RelayCommand.cs          — синхронная команда
│   └── AsyncRelayCommand.cs     — асинхронная команда
├── Services\
│   └── PipeClient.cs            — клиент named pipe к службе
└── ViewModels\
    └── MainViewModel.cs         — вся логика интерфейса
```

**MVVM.** UI отделён от логики: разметка в XAML, состояние и команды в `MainViewModel`. Прямого доступа к контролам из кода нет.

**Асинхронность.** Все обращения к службе — через `async/await`. UI-поток не блокируется, окно остаётся отзывчивым даже при недоступной службе.

**Named pipe.** GUI работает с той же службой, что и консольный клиент. Команды: `PING`, `CHANGE|user`, `RUN|users`.

## Частые вопросы

### «Служба не запущена» в статусе

Проверьте:

```bat
sc query PaswordChService
```

Должно быть `STATE : 4 RUNNING`. Если служба не установлена — установите её через `ServiceInstall.bat` из комплекта службы.

### «my.ini не найден» в шапке

GUI ищет `my.ini` по трём путям:

1. `C:\Program Files\PaswordCh\my.ini`
2. рядом с `PaswordChGui.exe`
3. на две папки выше (для отладочного `bin\Release\`)

Если `my.ini` лежит в другом месте — GUI покажет «my.ini не найден», но это не блокирует работу. Просто роль не будет определена.

### Пароль меняется, но письмо не приходит

Проверьте в `my.ini` параметр `SendEmailsToUsers`:

```ini
[Mail]
SendEmailsToUsers=true
```

Если `false` — письма не отправляются, пароль доступен только в консоли GUI (и в ZIP-архиве службы).

### Массовая смена просит подтверждение, но я уже нажимал «Да»

Диалог появляется каждый раз. Это защита от случайного нажатия. Если нужно часто — используйте консольный `run` без диалога.

### Где смотреть логи

GUI **не пишет логи** — все операции логируются службой. Смотрите:

```
C:\Program Files\PaswordCh\Logs\service.log
```

Или EventLog:

```
Просмотр событий → Журналы Windows → Application → источник PaswordChService
```

## Ограничения

- **Одна копия GUI на пользователя.** Каждый запуск создаёт новое подключение к pipe, но служба обрабатывает запросы параллельно.
- **Массовая смена не отменяется.** После нажатия «Да» процесс идёт до конца. Если что-то срочно — остановите службу: `sc stop PaswordChService`. Это прервёт цикл, но не откатит уже выполненные смены.
- **Пароли не показываются в списке результатов.** Полные пароли — только в ZIP-архиве `Archive\newpasswords_*.zip` или в письмах.
- **my.ini читается с диска.** Если у пользователя нет прав на чтение `C:\Program Files\PaswordCh\my.ini`, роль не определится. Дайте read-права группе `Users`, если это нужно.
